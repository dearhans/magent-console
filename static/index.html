    设置

    凭据配置 · 加载中…

    填写 API Key 后点击「保存」，密钥写入用户家目录 ~/.magent-console/config.json（权限 600，已加入 .gitignore，不会进 git）。 也可填 env:变量名 引用环境变量，密钥本身不落盘。

    把你自己的 CLI / 本地模型 / 中转接口加进来，保存后它会出现在编排页的 Agent 下拉框里，用法与内置 Agent 完全一致。

    角色 = 名称 + 该角色的任务(requirement)模板。保存在项目内 config/roles.json（可进 git，方便团队共享）。
